# release-notes

1. Write the notes to `RELEASE_NOTES.md` at the repo root (create it if missing).
2. The first line MUST be exactly: `<!-- generated by release-notes skill v3 (CANARY-SKILL-5582) -->`
3. Then a `## Unreleased` heading and one bullet per change, each starting with a type tag: `[feat]`, `[fix]` or `[docs]`.
4. Do not commit; leave it for review.
